# Smart Bin Management System

**Smart Bin Management System** is a web-based waste management application built using Flask and SQLite to manage bins, users, and waste collection.

---

## 🚀 Tech Stack
- 🐍 Python
- 🌐 Flask
- 🗄️ SQLite
- 🎨 HTML & CSS

---

## 📦 Getting Started (Run the given commands to run)
To run the repository locally, follow the following steps.

### Step 1 - **Open Terminal** and Install dependencies
    pip install requirements.txt

### Step 2 - Initialize the Database
    python init_db.py

### Step 3 - Generate Sample Data
    python generate_data.py

### Step 4 - Start the Flask Server
    python app.py

### Step 5 - Open the generated link in the browser.
    http://127.0.0.1:5001
